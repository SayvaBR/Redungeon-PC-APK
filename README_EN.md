# Redungeon — PC and Android

This public repository contains the playable builds and the source files needed to contribute:

- PC: run `JOGO REDUNGEON/PC/RedungeonPC.exe` on Windows.
- Android: copy `JOGO REDUNGEON/Android/Redungeon.apk` to the device and install it.

The game source is in `RedungeonPC_ResolutionManager`. The Android project is in `RedungeonPC_ResolutionManager/Android`.

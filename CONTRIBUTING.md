# Contributing to Redungeon

Contributions in this repository target the PC and Android versions of the game.

The shared game source is under `RedungeonPC_ResolutionManager`. Android-specific files are under `RedungeonPC_ResolutionManager/Android`.

## PC

Run `JOGO REDUNGEON/PC/RedungeonPC.exe` on Windows. PC changes must be tested in the Windows build before submission.

## Android

The current package is `JOGO REDUNGEON/Android/Redungeon.apk`. Install it on a test device and verify the affected feature before submission.

Please keep PC and Android behavior aligned whenever a change affects gameplay, controls, graphics, audio, or progression.

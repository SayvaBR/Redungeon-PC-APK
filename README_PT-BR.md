# Redungeon — PC e Android

Este repositório público contém as versões jogáveis e os arquivos-fonte para contribuir:

- PC: abra `JOGO REDUNGEON/PC/RedungeonPC.exe` no Windows.
- Android: copie `JOGO REDUNGEON/Android/Redungeon.apk` para o celular e instale-o.

O código do jogo fica em `RedungeonPC_ResolutionManager`. O projeto Android fica em `RedungeonPC_ResolutionManager/Android`.

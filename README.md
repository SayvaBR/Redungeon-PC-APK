# Redungeon — PC e Android

Idiomas / Languages: [Português (Brasil)](README_PT-BR.md) · [English](README_EN.md)

Este repositório público contém os entregáveis jogáveis e os arquivos-fonte necessários para contribuir com as versões PC e Android:

- PC: `JOGO REDUNGEON/PC/RedungeonPC.exe`
- Android: `JOGO REDUNGEON/Android/Redungeon.apk`

O código do jogo fica em `RedungeonPC_ResolutionManager`. O projeto Android está em `RedungeonPC_ResolutionManager/Android`.

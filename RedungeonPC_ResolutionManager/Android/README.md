# Redungeon Android — entrega atual

Versão 1.0.3 / código 4, ARM64, Android 8 ou superior.
APK único: `../../JOGO REDUNGEON/Android/Redungeon.apk`.
Pacote: `com.redungeon.personal`, mesma assinatura da versão anterior.

Execute `../Atualizar-Jogo.ps1` para atualizar PC e Android. O script usa uma área
física temporária sem acentos para o MGCB e a remove após uma compilação bem-sucedida.
O código Android referencia o código compartilhado do jogo.

Novidades: splash do capacete, fumaça roxa animada e vibração nativa com permissão
VIBRATE. Os controles e o restante do polimento compartilhado estão incluídos.

Esta versão foi compilada e assinada; ainda não foi instalada/testada fisicamente
no telefone nesta sessão. Não havia dispositivo conectado ao ADB.
Veja `../docs/validacao-1.0.3.md` e `../docs/entrega-atual.md`.
